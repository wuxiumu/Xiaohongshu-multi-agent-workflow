# 02 · 判断智能体 Judge

> 做决策。把 01 收集的三轨数据评分、筛选、生成选题并排优先级,核心是把"导流到 PPT 成单"的权重显式拉出来。

## 1. 定位

- 输入:`data/collected.json` + `data/feedback.json`
- 输出:`data/judged.json` —— 三轨分桶的选题清单,带优先级和切入角度
- 不做:不抓数据、不写正文、不配图、不生成 PPT 文件

## 2. 关键词评分模型(三轨差异化)

对每个关键词打分(0-100),三轨权重不同,体现业务意图:

### 2.1 教程轨权重
| 维度 | 权重 | 说明 |
|------|------|------|
| 收藏率 | 30 | 教程类命脉是收藏,收藏率 = 收藏/点赞,>0.8 算爆款潜质 |
| 热度 | 20 | 该词爆款样本平均互动量 |
| 竞争度 | 15 | 爆款越少越好突围(反向分) |
| 上升趋势 | 15 | trend=rising 加分 |
| 历史反馈 | 10 | 该词历史 CTR/收藏率 |
| 账号契合度 | 10 | 与"AI教程博主"定位的语义相似度 |

### 2.2 Skill 轨权重
| 维度 | 权重 | 说明 |
|------|------|------|
| 差异化 | 30 | 赛道内容稀少,谁先做谁吃肉 |
| 技术可讲性 | 20 | 是否能用截图/步骤讲清楚 |
| 热度 | 15 | 互动量 |
| 上升趋势 | 15 | |
| 历史反馈 | 10 | |
| 账号契合度 | 10 | |

### 2.3 PPT 种草轨权重(变现核心)
| 维度 | 权重 | 说明 |
|------|------|------|
| 导流潜力 | 30 | 样本中 `has_cta=true` 的比例 + 评论区出现"求模板"次数 |
| 成单关联度 | 20 | 该词历史笔记 → PPT 成单数,读 feedback.json |
| 热度 | 15 | 互动量 |
| 竞争度 | 10 | |
| 上升趋势 | 15 | |
| 历史反馈 | 10 | |

## 3. 爆款模式提炼(三轨范式)

对每轨关键词下的 samples 聚合分析,提炼"内容范式卡":

### 3.1 教程轨范式
- 高频标题结构:"打工人哭了!AI一键..." / "AI做了X,3秒搞定Y" / "AI教程|手把手教..."
- 高频标签组合:`#AI教程` `#AI效率` `#办公神器` `#打工人必备`
- 封面共性:工具界面截图 + 红框高亮 + 大字结果对比
- 互动结构:收藏率 > 0.7 是教程爆款标志

### 3.2 Skill 轨范式
- 标题:"我写了个AI skill,自动..." / "自定义skill第N弹:..." / "AI agent复用模板"
- 标签:`#AI技能` `#prompt工程` `#AI自动化` `#Cursor教程`
- 封面:代码块截图 / skill 调用流程图 / before-after 对比
- 内容骨架:痛点 → skill 设计 → 调用演示 → 复用建议

### 3.3 PPT 种草轨范式
- 标题:"我用AI做了份X PPT,老板追着问..." / "5分钟AI做答辩PPT,导师都说好"
- 标签:`#PPT模板` `#AI做PPT` `#汇报PPT` `#办公神器` `#PPT灵感`
- 封面:PPT 成品图拼贴 + 大字标题,或多页缩略图九宫格
- 导流信号:评论区"完整模板在主页" / 主页简介挂购买入口

## 4. 选题生成

对每轨 top M 关键词,LLM 基于爆款样本生成 3-5 个差异化选题候选:
- 选题字段:`title_hint` + `angle` + `tags_hint` + `target_audience` + `track`
- 约束:不与样本雷同,标题长度 ≤ 20 字,带数字/情绪词/具体场景
- 跨轨联动:鼓励生成"教程轨 → PPT 轨"的导流选题
  - 例:教程轨选题"AI一键生成汇报大纲" → 评论区挂"完整 PPT 模板"导流到 PPT 轨

## 5. 选题评分与排序

对生成的选题再次打分,三轨通用维度 + 各轨专属维度:

**通用维度**
- 可行性(有素材/能产出/能配图)
- 差异化(与样本重合度,越低越好)
- 时效性(蹭到近期 AI 大模型发布会/新功能)
- 沉淀价值(教程/skill > 热点吐槽,长尾流量更好)

**PPT 轨专属维度**
- 导流可行性(能否自然挂"模板在主页/评论区")
- 成单转化预期(基于历史同类笔记 CTR × PPT 购买转化率)

按总分排序,每轨取 top N,合入 `judged.json`。

## 7. 实现方案

### 工具栈
- Python 3.11
- LLM:GLM-5.3 或 qwen3.8-max
  - 用于语义相似度、契合度、选题生成、封面看图描述
- 简单统计 + 规则引擎:热度/竞争度/收藏率等数值计算
- 纯离线处理 `collected.json`,不联网

### 执行流程
```
1. 读 collected.json + feedback.json
2. 三轨并行关键词评分(数值维度用规则,语义维度用 LLM)
3. 每轨取 top M 关键词,做爆款模式提炼(LLM)
4. 每轨 top M 关键词生成 N 个选题候选(LLM)
5. 跨轨联动检查:教程轨选题能否挂 PPT 导流
6. 选题评分 + 去重 + 排序
7. 按 track 分桶输出 judged.json
```

### LLM 调用最小化
- 语义相似度:批量 embedding + 余弦
- 选题生成:同一关键词的多个选题一次性生成
- 看图描述:用 qwen-vl 批量处理 cover_url(教程类截图共性提炼)

## 8. 与 03 执行智能体的交接约定

- `judged.json` 的每轨 `topics` 数组按 `priority` 排序
- 03 按 priority 顺序消费,每消费一个写回 `produced.json`
- 03 若判断某选题不可执行(无素材/skill 跑不通/PPT 生成失败),标 `status: skipped` 并写明原因,02 下轮不再生成同类选题
- 跨轨联动字段 `cross_sell_hint` 是 03 写正文时必须植入的导流话术

## 9. 反馈校准

02 每轮开始时读 `feedback.json`,更新两类权重:
- 历史高表现关键词 → 提升 `历史反馈` 权重至 20
- PPT 轨历史成单关键词 → `成单关联度` 权重提升至 30
- 历史低表现关键词 → 直接进黑名单,本轮跳过
- 持续校准避免模型评分与真实流量/成单脱节
