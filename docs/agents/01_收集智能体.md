# 01 · 收集智能体 Collector

> 看市场。把 AI 教程、Skill 玩法、PPT 模板这三轨在小红书上的热点、关键词、爆款样本捞回来。

## 1. 定位

- 输入:`collect_config.yaml`(账号定位、三轨种子词、抓取数量)
- 输出:`data/collected.json` —— 三轨分桶的关键词库 + 爆款样本
- 不做:不做质量评判、不写正文、不直接产出可发布内容

## 2. 三轨关键词体系

赛道按内容轨拆三个桶,互不混桶,方便 02 做差异化评分:

```yaml
# collect_config.yaml 节选
tracks:
  tutorial:                 # 教程轨
    seeds: ["AI教程", "ChatGPT教程", "AI工具", "AI效率",
            "AI办公", "AI作图", "AI写作", "AI副业",
            "智谱AI", "通义千问", "Gemini教程"]
  skill:                    # Skill 轨
    seeds: ["AI技能", "AI agent", "prompt工程", "自定义skill",
            "AI工作流", "AI助手", "Cursor教程", "Claude skill",
            "MCP协议", "AI自动化"]
  ppt:                      # PPT 种草轨
    seeds: ["AI生成PPT", "PPT模板", "AI做PPT", "办公PPT",
            "汇报PPT", "答辩PPT", "PPT模板免费",
            "AI PPT神器", "PPT排版", "PPT灵感"]
```

## 3. 核心能力

### 3.1 关键词采集(三轨并行)
- **种子词扩展**:LLM 把每轨种子词扩成长尾词
  - 教程:`AI教程` → `AI一键做表格` / `AI生成思维导图` / `AI批量改写文案` ...
  - Skill:`自定义skill` → `怎么写skill` / `skill调用逻辑` / `AI技能复用` ...
  - PPT:`AI做PPT` → `5分钟AI做汇报` / `AI生成答辩PPT` / `AI PPT模板套用` ...
- **下拉词抓取**:小红书搜索框联想、抖音/微信搜一搜联想,补充到对应桶
- **趋势词监测**:小红书"热点"、微博热搜中 AI 相关词条(过滤泛娱乐)

### 3.2 爆款样本抓取
对每轨关键词,抓取搜索结果前 20 条笔记,提取:
- 标题、正文前 200 字、标签、点赞/收藏/评论数
- 封面图 URL(后续判断风格:教程类常见截图、PPT 类常见成品图)
- 发布时间(过滤超过 30 天的,保证时效)
- 评论区是否带"链接/主页/私信"等导流信号(标 `has_cta`,供 02 评估变现潜力)

### 3.3 跨平台信号
- 知乎:`AI教程` `prompt工程` 高赞回答标题(选题灵感,教程/skill 轨)
- 抖音:`AI PPT神器` 话题播放量(判断 PPT 轨热度天花板)
- B 站:AI 工具教程 top 视频标题(PPT 种草时可引用"UP 主同款思路")
- 微博:AI 大模型发布会/新功能热搜(蹭热点用,如智谱 GLM 新版本)

### 3.4 竞品账号监测
配置 5-10 个对标账号(教程型、PPT 模板型各一半),抓其最新 10 篇笔记:
- 标题、互动量、发布时段
- 是否带 PPT 模板导流(标签或评论)
- 用于 02 提炼"什么标题 + 什么封面更容易把人导流到 PPT"

## 5. 实现方案

### 工具栈
- Python 3.11
- `requests` + `playwright`(应对小红书反爬)
- LLM 调用:智谱 GLM-5.3 或百炼 qwen3.8-max,用于种子词扩展
- 配置文件:`_plan/collect_config.yaml`

### 执行流程
```
1. 读 collect_config.yaml + data/feedback.json
2. 三轨并行种子词扩展(LLM,每个种子词扩 5 个长尾)
3. 三轨并行抓下拉词 → 补全关键词库
4. 对每轨 top N 关键词抓小红书搜索结果 → 爆款样本
5. 抓对标账号最新 10 篇
6. 跨平台信号补充(可选,限频)
7. 按 track 分桶写入 collected.json
```

### 反爬与合规
- 单账号小流量,每关键词间隔 3-5 秒,每日总抓取 ≤ 200 条
- 不抓用户隐私,只取公开笔记聚合指标
- 遵守 robots.txt,优先用搜索结果页而非详情页深度爬取
- 对标账号监测只抓标题 + 互动数,不抓正文

## 6. 示例运行(本赛道)

种子词 11 + 10 + 10 = 31 个,扩展后:

1. 教程轨:31→50 词,抓 300 样本(高质量教程爆款多)
2. Skill 轨:10→25 词,抓 100 样本(skill 赛道内容稀少,这是机会)
3. PPT 轨:10→30 词,抓 200 样本(PPT 模板爆款集中)
4. 对标账号 8 个 × 10 篇 = 80 篇竞品笔记
5. 跨平台补 20 条选题信号
6. 输出 `collected.json`,交 02

## 7. 失败与降级

- 小红书限流 → 切换账号/降频/当日跳过,只跑关键词扩展
- LLM 失败 → 用种子词直接搜索,不扩展
- 跨平台信号失败 → 主流程不受影响,`cross_platform` 字段置空
- 对标账号抓取失败 → 标 `competitors: []`,02 不依赖此字段做主决策
